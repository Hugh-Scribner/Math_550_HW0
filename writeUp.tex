\section{Problem 1}
 \begin{tcolorbox}
        \textbf{Problem Statement:}\\
        Write a matlab code that uses finite differences to compute
        the first derivative of
        \[f(x) = \text{exp(sin(x))}\]
        on the internal [0,$2\pi$]. Use second-order centered differences on internal grid points and first-order one-sided differences at endpoints.
    \begin{enumerate}
        \item Show a graph of the exact analytic solution $f'(x)$ and your numerical solution $f_n'(x)$.
        \item Show a relative error convergence plot by plotting the relative error on the y-axis and the
        grid size N on the x-axis. Plot the error using both the $p = \infty, 2$ norms in a log-log scale.
        \item We see a curve with a slope 3/2, why?
    \end{enumerate}
        
    \end{tcolorbox}
    
    \textbf{Solution:}
        \begin{enumerate}
            \item A Finite difference approximation of the first derivative of $f(x) = \text{exp(sin}(x))$ was taking using N = 21. The results are shown in figure \ref{fig:finite_diff_1} below.
                \begin{figure}[H]
                    \begin{centering}
                    \centering
                        \includegraphics[scale=.75]{Images/problem1_1.png}
                        \caption{Finite difference approximation (N=21) of first derivative of $f(x) = \text{exp(sin}x))$. The exact solution is shown in blue and the numerical solution is shown in red.}
                        \label{fig:finite_diff_1}
                    \end{centering}
                \end{figure}
            \item A convergence plot for the FD model is provided in figure\ref{fig:convergence_1}. The plot makes clear that the $L_2$ error is $\mathcal{O(h^{3/2})}$, and the $L_\infty$ error is $\mathcal{O}(h)$.
                \begin{figure}[H]
                    \begin{centering}
                    \centering
                        \includegraphics[scale=.75]{Images/problem1_2.png}
                        \caption{Convergence plot with $L^2$ and $L^\infty$ norms of absolute error for finite difference approximation shown in figure 1.}
                        \label{fig:convergence_1}
                    \end{centering}
                \end{figure}
            \item The absolute error for the case where the derivative at the end points is approximated by first order finite differences can be rewritten using asymptotics as follows:

            \[ \frac{\lVert f(x_i) - f_n(x_i)) \rVert_2}{\lVert f(x_i) \rVert_2} = \frac{\sqrt{(\mathcal{O}(h) + \mathcal{O}(n)\mathcal{O}(h^2))^2}}{\sqrt{\mathcal{O}(n)}} = \frac{\mathcal{O}(h)}{\sqrt{\mathcal{O}(n)}}\]

            Since $n = \frac{1}{h}$, $\mathcal{O}(n) \propto \mathcal{O}(h^{-1})$, so error can be further simplified as 

            \[\frac{\mathcal{O}(h)}{\sqrt{\mathcal{O}(h^{-1})}} = \mathcal{O}(h^{3/2}).\]
        \end{enumerate}

\section{Problem 3}
 \begin{tcolorbox}
        \textbf{Problem Statement:}\\
        Consider the ODE
        \begin{equation}
            \frac{d^2u}{dx^2} + sin(x)\frac{du}{dx} + u(x) = f(x)
            \label{eqn: prob 3}
        \end{equation}
        defined on $0 \leq x \leq 5$. Solve the ODE using second-order finite difference methods with the Dirichlet conditions. Use $u(x) = sin(x)$ to test your solution by finding boundary conditions and the necessary forcing function $f(x)$. Show an error plot that proves your method converges with second order.
        
    \end{tcolorbox}
    
    \textbf{Solution:}
        Applying finite differences to equation \ref{eqn: prob 3} we can rewrite the problem as

        \begin{equation}
            u_{i+1}\left( \frac{1}{h^2} + \frac{\sin(x_i)}{h}\right) + u_i \left( 1 - \frac{1}{h^2}\right) + u_{i-1}\left( \frac{1}{h^2} - \frac{\sin(x_i)}{h}\right) = \sin(x_i)\cos(x_i),
            \label{eqn: finite_diff_ode}
        \end{equation}

        where $x_i, u_i$ denote the values of x and u at the ith node of the finite difference mesh. $u_0$ and $u_n$ are held at the appropriate boundary values. Solving the system defined by equation \ref{eqn: prob 3} for n = 50 gives the result shown in \ref{fig:sol_3}.
        \begin{figure}[H] 
                \begin{centering}
                    \centering
                        \includegraphics[scale=.75]{Images/problem3_1.png}
                        \caption{Finite difference approximation (n=50) of solution to equation \ref{eqn: prob 3} The exact solution is shown in blue and the numerical solution is shown in red.}
                        \label{fig:sol_3}
                    \end{centering}
                \end{figure}

        Plotting the error, it can once again be seen that the finite difference approximation has second order convergence.
        \begin{figure}[H]
                \begin{centering}
                    \centering
                        \includegraphics[scale=.75]{Images/problem3_2.png}
                        \caption{Convergence plot with $L^2$ norms of absolute error for finite difference approximation in equation \ref{eqn: finite_diff_ode}.}
                    \end{centering}
                \end{figure}

\section{Problem 4}
 \begin{tcolorbox}
        \textbf{Problem Statement:}\\
        Use finite difference methods to solve the Poisson equation $\nabla^2u = f (x, y)$ in the domain $x \in [0, 5],\ y \in [0, 5]$. Use the test solution $u(x, y) = sin(x) cos(y)$
        \begin{enumerate}
            \item Apply Dirichlet conditions on all boundaries so that $u(x, y)$ satisfies the PDE and the boundary conditions, and show a plot of your solution and a second order convergence plot (similar to the first three problems).
            \item Modify your code to apply Neumann conditions on all boundaries. This won’t work. Why not? Both in terms of the linear algebra and in terms of the actual PDE we want to solve. Suggest a solution to the issue.
        \end{enumerate}
            \end{tcolorbox}
    
    \textbf{Solution:}
        \begin{enumerate}
            \item Figure \ref{fig:poisson_sols} below depicts the exact and numerical solutions to the Poisson equation with $f(x) = -2\sin(x)\cos(x)$ for n = 1600. Using the eyeball norm, the solutions are identical.

                            \caption{The above figure depicts the exact and numerical solutions to the Poisson equation.}

                    \end{centering}
                \end{figure}
                
            Since the error in the numerical solution is not easily visible by inspection, figure \ref{fig: prob_4_error} provides an error plot.

                Running the numerical simulation for denser and denser meshes, it is found that the finite difference model once again demonstrates second order convergence, as shown in figure \ref{fig: Poisson_convergence}
            \item
            Attempting to adapt the FD solver to handle the same problem as above but with Neumann boundary conditions results in the solution shown in figure \ref{fig: Neumann_bcs}.
                \begin{figure}[H]
                    \begin{centering}
                        \centering
                            \includegraphics[scale=.75]{Images/problem4_4.png}
                            \caption{Convergence plot with $L^2$ norms of absolute error for finite difference approximation in equation \ref{eqn: finite_diff_ode}.}
                            \label{fig: Neumann_bcs}
                    \end{centering}
                \end{figure}

            As the figure above makes clear, the finite difference solver diverges for these boundary conditions. This is because linear system used to approximate the laplacian operator becomes singular when neumann boundaries are applied. Numpy estimated the condition number of the corresponding A matrix corresponding with a 40 by 40 grid to be 1.17e17. This occurs because there are infinite solutions to Poisson's equations when the only specified boundary conditions are Neumann. To address these issues there are two paths forward:
            \begin{enumerate}
                \item Gather more data regarding the system being analyzed to impose additional conditions on the solution to narrow the solution space to one answer (This would be the best path forward if you are trying to model a system which you can gather data about).
                \item Impose an additional constraint on the loss function used to solve the poisson equation to select an "optimal" solution from the solution space (This would be the best fit if you are trying to solve a design problem where multiple solutions are valid).
            \end{enumerate}

        \end{enumerate}
